# stacker

A collage maker. Drop in photos, add colour blocks, circles, grids and crosses, move, scale and rotate them (pieces can run off the edges), give it all a printed texture, and export a PNG or a video of the pieces being stuck down one by one.

- Images arrive printed: grain, paper warmth and softened blacks, with a little show-through. Each piece can have more or less texture and show-through, multiply onto what's beneath, be cut to a circle, go black and white, or have a torn edge.
- Randomise reshuffles positions, sizes, tilts and stacking order across the board.
- Artboard formats 4:5, 1:1, 9:16, 16:9 and A4, any background colour, and grain, paper, print dots and fade over the whole thing.
- Drag to move, corner handles to scale (Alt: from the centre), just outside a corner to rotate, scroll to scale, shift-scroll to rotate, pinch and twist on touch. Undo with ⌘Z; ] and [ change order; ⌘D duplicates.
- Your collage, images included, is kept in this browser.
- Sample photos are free photos from [Unsplash](https://unsplash.com), served by [Lorem Picsum](https://picsum.photos).

Built on [veryrobert/starter](https://github.com/veryrobert/starter): React, TypeScript, Vite, Tailwind v4, shadcn/ui, Lucide.

```bash
npm install
npm run dev
```
